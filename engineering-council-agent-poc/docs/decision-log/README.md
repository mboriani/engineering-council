# docs/decision-log

Detailed, long-form decision records that don't warrant a full ADR but are
worth more than a single row in the top-level [`DECISION_LOG.md`](../../DECISION_LOG.md).

- The **summary table of all decisions** lives in the root `DECISION_LOG.md`.
- **Architectural** decisions are promoted to [`../adr/`](../adr/).
- Put one file per decision here when it needs context, alternatives considered,
  or diagrams. Suggested name: `YYYY-MM-DD-short-slug.md`.
