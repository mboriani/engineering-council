# docs/memory

Durable, topic-scoped memory files that support the top-level
[`PROJECT_MEMORY.md`](../../PROJECT_MEMORY.md).

- `PROJECT_MEMORY.md` (root) is the **index / overview** — read it first.
- Put deeper, single-topic notes here (one file per topic) when the root file
  would get too long: e.g. `agent-framework-api-notes.md`, `provider-matrix.md`,
  `dashboard-contract.md`.
- Keep entries factual and current; delete what becomes wrong.
